About Strata

Strata reads a GitHub repository and explains how it is built. Every capability is exposed through a real Model Context Protocol server, so the same tools can be used by this interface, by Claude Desktop, or by any other MCP-compatible client.

Web UI→FastAPI→ MCP → Analyst Server→GitHub + LLM

API

A service you call. Here: the GitHub REST API and the OpenRouter LLM API.

Tool calling

A model choosing which function to run, based on a schema it was given.

Agent

A loop that plans, calls a tool, observes the result, and decides what to do next.

MCP

The standard that exposes tools so any client can discover and call them the same way.
